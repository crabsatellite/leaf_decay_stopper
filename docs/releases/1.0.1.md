# Leaf Decay Stopper 1.0.1

Bug fixes since 1.0.0 for Forge 1.20.1 and NeoForge 1.21.1.

- Fixed decay toggles when a dimension appears more than once in the config. (#1)

- Corrected invalid config IDs while preserving empty lists and temporarily absent mod dimensions. (#3)
- Fixed live config reload after ordinary and replacement saves on Forge. Commands still apply immediately. (#10)
- Restored Forge 47.3.0 startup compatibility and corrected update-check information. (#5, #4)
